# Wavy-Flo

Motion graphics and music videos, in real time, for Windows.

## Download
Get the newest **Wavy-Flo-…-win64.zip** from
[Releases](https://github.com/Keblackan/Wavy-Flo-Releases/releases/latest).

1. Unpack the zip anywhere, for example in Documents.
2. Open **Wavy-Flo.exe**.

Windows may say "Windows protected your PC" the first time:
choose **More info > Run anyway**.

## Updates
Wavy-Flo looks for a newer version as it opens. Press **Update** and it
downloads, installs and opens again by itself.

This repository holds only the downloads. Wavy-Flo's source is not here.
